# v0.3.61

## 变更

- getExGameList/getRelatedByTag的有限结果集先按原有过滤、作用域、排序与LIMIT选择ID，再获取完整文章和分类，避免把content/expand大字段放入大量候选行的临时表排序。保持返回模型、顺序、设备/蜘蛛/专题可见性；不限制条数的调用保留原行为。
- 首页静态化增加连接/总超时、HTTP200和完整HTML验证，拒绝is_static响应。成功时同目录临时文件原子替换；失败保留旧首页、返回非零、记录不含admin_key的日志，队列抛出失败。只配置PC的站点可跳过移动端，完整的小主题无最低字节数限制。
- 包含上一版本后已提交的友情链接模块缺失时自动创建修复。

## 验证

在开发宿主运行（不启动应用、不连接业务数据库）：

```bash
php vendor/bin/phpunit --no-configuration --bootstrap vendor/autoload.php core/tests/CoreReleaseRegressionTest.php
```

13项SQLite内存库/模拟HTTP回归、88个断言，覆盖访客与蜘蛛、PC/移动端、隐藏/下架/软删除、排序与完整模型、空集/无限制/offset、标签分类与排除自身、HTTP错误/超时/静态响应/残缺HTML、旧文件保护与队列失败。

本地core数据库4033项关联取8条，结果ID相同且正文/分类完整。单次基准原查询约890ms、优化后约86ms；存在缓存与环境差异，不能作为线上性能承诺。

## 部署

本版无新增数据库迁移。ADMIN_VERSION=v0.2.17、GO_VERSION=v0.0.8不变。

发布包名library.zip，发行版tag必须与version.json一致。先试点再升级目标站；保留本站composer/queue等部署差异。根据真实OPcache设置使FPM生效，并定向重启常驻队列worker；不要清共享Redis库。

静态化仍通过本站配置域名请求。源站迁移时需配置正确DNS/本机回源解析并保证TLS证书有效；不要将某台服务器的127.0.0.1解析或关闭TLS写进通用core。该版本会明确暴露回源故障，不会自动修复DNS/证书。
